# Chunk 4d results: sampled-HeI state switch (discrete reset and packing)

NOTICE: port of ORIGINAL CosmoRec v3.0b (SHA 086769055f61ae0c244a53dd381ee65b624d0ac3), (c) J. Chluba et al. Use must be acknowledged; cite Chluba & Thomas 2010 (MNRAS 412, 748), Chluba & Sunyaev 2006 (A&A 446, 39), Rubino-Martin, Chluba & Sunyaev 2008. No native source or data was changed.

## Scope (and nothing more)
`src/HeliumSwitch.jl` (included from `src/CosmoRec.jl`, exports added) and the `helium = false` branch of `pack_ysol` (`src/SahaInit.jl`) port the sampled-HeI state switch of `Modules/main.CosmoRec.cpp:163-197` as a DISCRETE operator on explicit state:
- decision `helium_switch_condition(zs, fHe, X_He1s)` = `(zs < 200 || fHe - X_He1s <= Xi_HeI_switch) && flag_He`, `Xi_HeI_switch = 1e-7` (`global_variables.cpp:37`), evaluated on PRIMAL values;
- reset `helium_switch_reset(X, nH, nHe, fHe)`: He 1s (`X[2 + nH]`) = `fHe`, all other helium slots = `1e-300` (the native floor), `Xe`, the hydrogen levels and `rho` unchanged; always returns a copy;
- `helium_switch` (decision + reset with a frozen branch), `helium_switch_ysize` (`2 + nres_HI + (helium ? 1 + nres_HeI : 0)`), and `pack_ysol(...; helium = false)` = native `copy_LI_to_ysol` with `flag_He = 0`: `[rho, H 1s, 5 resolved H]` (length 7 instead of 12).
The reset depends on `fHe` (the helium ground slot becomes `fHe`). NOT implemented: the ODE, the solver restart, the event location in z, any derivative of the event location: the decision is piecewise constant and the state dimension changes, so no continuous event sensitivity exists or is claimed (tests state this explicitly).

## Results (focused: native 984/984, AD 32/32)
- All 80 native states: decision, post-state (including the 1e-300 floors and the unchanged `Xe`, H, `rho`), `HeI_Atoms.Xi(i)`, pre- and post-packed vectors and vector lengths BITWISE equal (0.0 error). The rounding boundary of the criterion is reproduced exactly (e.g. `fHe - (fHe - 1e-7)` evaluates to 1.0000000000287557e-7 > 1e-7: not switched; `fHe - (fHe - 9.9999999e-8)` switches), because the decision uses the same floating-point difference as the native code.
- A bug found by the tests and fixed: the first `helium_switch_reset` aliased a `Vector{Float64}` input through `convert`; the native-state test exposed the in-place mutation; it now copies (test added: input unchanged).
- Discreteness tests: derivative of the decision is identically 0 on both sides; the state as a function of X[He 1s] has derivative 1 (unswitched) vs 0 (switched) across the criterion with a jump of 2e-7 in He 1s and the helium excited levels dropping to 1e-300; the packed length changes 12 -> 7.
- AD of the FROZEN-branch reset/pack operator with respect to the 15 state entries and `fHe` (switched, not switched, switched by zs < 200): ForwardDiff vs 256-bit central differences 0.0 (the operator is linear/piecewise constant); structure verified (retained entries identity, helium entries constant, no `fHe` dependence in the packed vector after the switch since helium is dropped; He 1s passes through when not switched; the reset state before packing has d/dfHe = 1 only in the He 1s slot); prepared Mooncake VJPs (two independent preparations, changed inputs) vs ForwardDiff `J'w` 0.0.
- Limitations: no event-time sensitivity; AD changes of inputs must keep the frozen branch (perturbations that cross the threshold change the branch and the dimension); only the production atoms (3-shell H, 2-shell He) and `flag_He` 1 -> 0 are covered.
